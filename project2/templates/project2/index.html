λ is not the penalty used while fitting. Each model in the grid below was fitted with its own regularization setting, and λ only decides which of the finished models is worth showing.

Every model in the grid is a point. The dashed line has slope λ and passes through the winner, so a model sitting above that line would have scored higher and one below it scored lower.

Slide λ to the right and the winner walks down and to the left: accuracy is being sold off for a shorter explanation. At λ = 0 the most accurate model always wins, however tangled it is.

Task 5 · global model agnostic methods

Feature effect plots

Both plots are computed from the {{ model_label|lower }} currently selected above.

Which derivative

ALE integrates the average partial derivative of the predicted probability with respect to the feature.

ALE_c(v) = ∫ E[ ∂f_c/∂x_s | x_s = z ] dz

{% if kind == 'logreg' %}

For logistic regression that derivative is exact. With softmax probabilities p and coefficients W, ∂p_c/∂x_s = p_c (W[c,s] − Σ_k p_k W[k,s]) / scale_s, which is what this plot uses. Computing the same curve by finite differences instead agrees to within {{ ale_gap }}, which is a useful check that the two agree.

{% else %}

A decision tree is piecewise constant, so its derivative is zero almost everywhere and undefined on the split points. There is nothing useful to integrate, so the derivative inside each bin is replaced by the finite difference across that bin's edges. That is what this plot uses.

{% endif %}

PDP holds the rest of the row fixed and forces the feature to each value on a grid, which breaks down when features are correlated: it averages over penguins that could not exist. ALE only ever compares predictions inside a narrow band of the feature, so it stays on the data. On this dataset flipper length and body mass are strongly correlated, so the two plots are worth comparing directly.
